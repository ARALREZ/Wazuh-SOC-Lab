# Project 03 — Lab Incident Reports

The reports in this directory are controlled lab investigation examples based on documented rule tests. They are not claims of real-world compromise. Alert timestamps, full event IDs and exact file names must be copied from the corresponding sanitized alert JSON before a report is presented as a complete case record.

| Report | Rule family | Evidence |
|---|---|---|
| `01-ssh-configuration-change.md` | 100031 | `evidence/100031_ssh_config_change.png` and corresponding alert record |
| `02-authorized-keys-change.md` | 100032 | `evidence/100032-authorized-keys-change-agent.png` and Who-data extract |
| `03-persistence-and-critical-file-change.md` | 100033, 100035, 100036, 100037 | Corresponding rule screenshots and alert records |

Do not include public-key contents, secrets or credentials in the report.
