# Expected Results — Project 03

## Quarantine runner

| Area | Expected result |
|---|---|
| Initialization | Quarantine directory root:root `0700`; audit log root:root `0600` |
| Quarantine | Source disappears; root-only payload and manifest exist |
| Integrity | SHA256 unchanged; same device/inode; size, UID, GID, mode and mtime preserved |
| Manifest | Version `2`, original path, SHA256 and metadata object |
| ACL | Preserved when ACL tools and filesystem support are available; otherwise reasoned SKIP |
| User xattr | Python API preserves test attribute when supported; otherwise reasoned SKIP |
| Restore conflict | Restore refuses existing destination; blocker and payload unchanged |
| Successful restore | Original path recreated; SHA256 and metadata match; item removed only after successful restore |
| Negative inputs | Symlink, FIFO, hardlink, outside root, traversal and symlink item refused |
| Audit | Exactly one `quarantine` and one `restore` record for the current fixture; valid JSON and expected SHA256 |

## Manager FIM integration

For benign files created inside the lab watch directory:
- baseline FIM rule `100030` may be generated;
- sensitive rules `100031–100037` must not be generated by those benign fixtures;
- Who-data must be interpreted only from fields present in the event;
- the test ID and timestamps must match the Agent report.

## Status semantics

- PASS: observed output matches the expected result.
- FAIL: observed output differs from expectation or a safety invariant is violated.
- SKIP: test could not be performed; include exact reason. SKIP is not PASS.
