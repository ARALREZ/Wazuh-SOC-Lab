# Evidence Collection

Store sanitized screenshots, terminal output, and test notes here.

Suggested evidence names:

- `server-services-healthy.png`
- `agent-active-in-manager.png`
- `ssh-failed-login-alert.png`
- `fim-file-modified-alert.png`
- `fim-file-created-deleted-alert.png`

Before committing evidence, remove passwords, API tokens, agent keys, private certificates, session cookies, and any unrelated personal information. Do not commit `client.keys`, `wazuh-install-files.tar`, or raw credential files.
